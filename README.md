# OluBitsFinOps
## Overview
OluBitsFinOps is a financial operations platform built with ASP.NET Core to help SMEs manage accounts, transactions, transfers, income, expenses, and other financial operations.
OluBitsFinOps is expected to help an SME record, organize, monitor, and report its financial activities through an API. 
## Objectives
1.	Provide SMEs with APIs for managing core financial operations.
2.	Maintain secure and auditable financial transaction records.
3.	Build a reliable and maintainable financial operations platform using modern software-engineering practices.
## Technology Stack
-	C#
-	ASP.NET Core/.NET 10
-	Git/GitHub
-	Azure DevOps.
